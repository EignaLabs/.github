# EignaLabs .github

This repository holds the public profile page of the EignaLabs organization on GitHub. GitHub shows `profile/README.md` on the organization page. The repository also holds the shared rules for agents and contributors in all EignaLabs repositories.

## Setup and use

This repository has no code and no build step. To change the organization page, do these steps:

1. Edit `profile/README.md`.
2. Put new images in `profile/assets/`.
3. Open a pull request.

## Tests

This repository has no git hooks and no automatic tests. Before you push, read your change on the GitHub preview of the file.

## Where things are

- `profile/README.md`: the text of the organization page.
- `profile/assets/banner.svg`: the banner at the top of the organization page.
- `profile/assets/eigna-mark.svg`: the Eigna mark at the bottom of the organization page.
- `AGENTS.md`: the rules for agents in this repository.
- `CODING_STANDARDS.md`: the rules for pull requests, the coordinator work queue, tests and local gates.
- `GLOSSARY.md`: the domain terms of this repository.
- `docs/assets/readme-hero.webp`: the image at the top of this file.
